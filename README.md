# Anti-Human Tests · 反人类测试合集

一个纯前端的恶搞小玩具，生成 Java 看了都想辞职的崩溃日志。

## 在线体验

直接点开仓库里的 `index.html` 即可玩，无需安装、无需联网、无需后端。把 `index.html` 下载到本地，双击用浏览器打开就能用。

## 功能列表

- 自定义包名（package）、类名（class）、异常消息（message）
- 可选 `Caused by` 消息与类名，自动拼出嵌套异常
- 四种日志格式：裸异常（printStackTrace）、Log4j 风格、Forge/NeoForge 风格、完整崩溃报告
- 🎲 随机生成：一键填入人类迷惑行为文案
- 📋 示例输出：一键填充一组搞笑示例并生成
- 📋 复制：一键复制生成的日志，按钮短暂变为「已复制 ✓」
- 一堆东西乱飞的猎奇动效、故障闪烁、整页抖动，可一键关闭
- 移动端适配，无横向滚动
