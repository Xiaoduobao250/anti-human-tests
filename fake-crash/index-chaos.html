🧾 常见崩溃速查（真实知识，非伪造）

java.lang.NullPointerException
最常见。某个字段在渲染/网络线程里还是 null，通常是客户端模组跑到服务端逻辑里去拿 level。

java.lang.OutOfMemoryError: Java heap space
堆不够。加 -Xmx4G 或减少模组；也可能是某个模组在无限缓存贴图。

java.lang.NoSuchMethodError
模组编译时用的 API 与运行时的 MC/Forge 版本不一致。经典版本错配。

Mixin apply failed
两个模组同时注入同一个方法。日志里往上翻能看到是哪个 mixin 先动的手。
