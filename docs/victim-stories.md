# 受害者故事集 · Victim Stories

> 以下故事**全部是编的**（或者至少我们拒绝承认是真的）。
> 如果其中有你的影子，那说明这个项目成功地冒犯到了正确的人。

按受害方式分类收录。最后附**幸存者指南**。

---

## 一、友尽篇

### 「你再说一遍这是日志？」

**受害者**：@阿哲（化名，因为他不让我们写真名）

我给朋友发了一份崩溃日志，问他能不能帮我看看。
他花了二十分钟认真分析，指出「`com.smelly.sock.SmellySockMod` 这个模组有问题，建议禁用」。

我：「那是假的，我手打的。」

他沉默了很久，回了句：「我把你当兄弟，你把我当编译器。」

**教训**：`Caused by: Java got suffocated by a smelly sock` 里出现「袜子」这个词的时候，正常人就该警觉了。

---

### 「你的模组叫什么东西？」

**受害者**：@小林

他在群里求助：「我装了 47 个模组，现在崩了，谁知道是哪个的问题？」

我发了 `java-crash/` 的链接给他。他非常认真地打开了。

十分钟后：

> 「……你这里面有个 `F**kWatermelonException` 和 `PizzaWasColdException`。
> 我查了半天，以为是我哪个模组的中文注释乱码了。」

**教训**：当一个类名里带表情符号的时候，它大概率不是真的。

---

### 「我按你说的做了」

**受害者**：@老周

我告诉他：「崩溃了就先看 `Caused by` 最下面那行。」

他照做了。那行的内容是：

```
Caused by: 你昨天说'肯定不会崩'昨天
```

他盯着这句话看了很久，然后把我拉黑了。

**教训**：这句建议本身是对的。只是这次日志是假的。

## 二、砸键盘篇

### 「进度条到 87% 的时候」

**受害者**：@大鹏

他在测试我们还没发布的一个页面（`fake-download/` 的原型）。

进度条冲到 87%。

然后停住了。

「当前速度：0 B/s — 正在从 1998 年的服务器重试…」

他等了三分钟。进度条**倒退**到了 84%，显示「缓存回滚」。

他等了两分钟。又回到 87%。

我听见他那边传来一声闷响。后来他解释说那是鼠标，不是键盘。我们选择相信他。

**教训**：87% 这个数字是从现实世界抄来的。

---

### 「stop 到底能不能 stop」

**受害者**：@匿名服务器管理员

我在他的服务器上演示 `fake-console/`。

他输入 `stop`。控制台回复：

```
> stop
[WARN] Server is not in a state that allows stopping right now.
[INFO] Try again. Maybe the second time it will work.
```

他又输了两次。第三次才成功停服。

**问题是那是个真服务器。**

**教训**：演示假控制台前，请确认你面前的是假控制台。

---

### 「这题答案是 0」

**受害者**：@Kevin

他做 `cpp-quiz/ub.html`，第一题：

```cpp
int x = 1;
x = x++ + ++x;
std::cout << x;
```

他的答案：「3」。

正确答案：「标准不保证。这是未定义行为，任何结果都合法，包括编译器把你的猫变成负数。」

他坚持认为这题出错了，去查了标准文档。

**他查了两个小时，最后承认我们是对的，然后把键盘推到了桌子另一边。**

（那个键盘目前还在那里。）

**教训**：UB 专场里，唯一错误的答案是「某个具体数字」。

## 三、闪瞎眼篇

### 「我点了那个按钮」

**受害者**：@Nico

页面上写得很清楚：

> 💥 让我崩溃
> ⚠️ 光敏性癫痫患者绝对不要点！出事了作者概不负责。

弹窗也拦了一次，明确写了「光敏性癫痫患者绝对不要点」。

他点了。确认了。然后：

- 整页抖动
- 全屏故障扫描线
- 反色闪屏
- 四十个 💀 和 🧦 在屏幕上乱飞
- 一个 8-bit 的方波音效在惨叫

他后来说：「我本来只是想看看你说的『混沌』是什么意思。」

**教训**：我们警告了两次。你自己点的。

（我们后来加了第三次警告和「安静模式」，但那是他之后的事。）

---

### 「🕷️」

**受害者**：@不知名的实习生

他在开放办公室里点开了 `mc-crash/chaos.html`。

混沌版有一题，乱飞效果的字符池里包含 🕷️。

他站起来的速度打破了该办公室的物理记录。

**教训**：公用电脑上不要点带「混沌」字样的按钮。

## 四、被室友 / 同事投诉篇

### 「你电脑怎么了」

**受害者**：@阿哲（又是他）

他在宿舍跑 `fake-crash/`，把输出音量开到最大（页面的 beep 音效）。

室友以为他的电脑真的要炸了，从床上跳下来问他要不要拔电源。

他说不用，这是网页。

室友说：「网页为什么要叫。」

**教训**：本项目默认开启音效。在安静场合请先关掉，或者点「🧘 关闭猎奇动效」。

---

### 「你是不是在挖矿」

**受害者**：@某公司的一位后端

他在公司电脑上打开了 `fake-console/`。

TPS 数值开始持续下降。CPU 占用（他以为的）也在涨。

IT 部门的人过来看了一眼满屏的 `[WARN] Can't keep up! Is the server overloaded?`

他花了十五分钟解释这只是个网页。

**教训**：这不是挖矿。`fake-console/` 一个网络请求都不发。
但你的 IT 部门不会立刻相信这一点。

## 五、自我怀疑篇

### 「我算错了三次」

**受害者**：@一位数学系学生

`number-theory/` 里有一题：求 `3^100 mod 7`。

他算出了 4，输入，对了。

下一题：求 `φ(100)`。他输入 40，对了。

再下一题：求 `2^64 mod 97`。

**他算了三次，每次答案都不一样，然后开始怀疑自己是不是不配读数学系。**

正确答案是 1。（`2^48 ≡ 1 (mod 97)`，因为 97 是素数且 `2^48` 的阶整除 96；
`64 = 48 + 16`，所以要再乘 `2^16 mod 97 = 65536 mod 97 = 65536 - 97*675 = 61`。）

……等等，我们让作者重新算了一遍。**正确答案是 61**。

**教训**：本页的数学是认真的。如果你算出的答案和我们对不上，
请先骂作者，然后**去看 `why` 里的推导过程**——那里写了每一步。

（顺便：如果你读到这里发现我们上面那行推导写错了，欢迎提 Issue。真的。）

---

### 「我居然被骗了」

**受害者**：@所有人

`mc-crash/mixed.html` 里，公平题和陷阱题是交替出现且**不告诉你是哪个**。

结果：真正的老手反而比新手错得多。

因为新手每一题都老实地读日志，而老手**知道自己会读日志**，于是每一题都自信地读，
在陷阱题上摔得比谁都惨。

**教训**：这是本系列最恶毒的一版。
它的目标不是知识，而是**你对你自己方法论的信心**。

## 六、幸存者指南

如果你已经受害，请按以下步骤处理：

1. **停止点击那个按钮。** 真的，立刻。
2. **点 `🧘 关闭猎奇动效`**（右上角），或按 `⏹ 停止一切动效`。所有效果会立刻停止。
3. **如果你感到不适**（头痛、眩晕、恶心），请离开屏幕，闭眼休息，必要时就医。
   页面上的警告不是装饰。
4. **向朋友道歉。** 尤其是你把他拉进来测试的时候。
5. **把 `仅供娱乐` 这四个字读三遍。**
6. **然后回到 `mc-crash/` 认真做一遍正经版。** 那一版是真的想教你点什么。

但欢迎把你的故事写进这里。
